Section 03

Limitations

해결하지 못했거나 검증하지 않은 부분

  • AI 작업은 OpenAI RPD 제한으로 Queue 적체가 남아 있습니다. API 에러율 0%는 요청 접수 기준이며, 표준 부하 테스트에서 ai-queue에 최대 11,227건이 쌓였습니다(Oldest Message Age 최대 513초).
  • Connection 고갈은 테스트 조건에서 재현되지 않았지만, 충분한 운영 여유를 검증한 것은 아닙니다. 최대 관측 74(max_connections 79) 중 애플리케이션 연결은 64였고, 나머지 세션의 정확한 종류는 확인하지 못했습니다.
  • VU는 실제 사용자 수가 아닙니다. 각 VU는 기록 생성과 상세 조회 요청 2건을 수행한 뒤 1초 대기하는 동작을 반복하며, 표준 부하 테스트의 평균 처리량은 약 34 req/s입니다.
  • AWS 프리티어 종료 후 비용 발생을 방지하기 위해 인프라 리소스를 중지 또는 삭제했습니다. 모든 수치는 테스트 당시 수집한 지표와 로그를 기준으로 합니다.
