# engineering-notes — AWS 아키텍처 관점 재검토

Moodot 부하 테스트 프로젝트(`../bottleneck_experiments/`)에서 구성한 인프라를 AWS 아키텍처 관점에서 다시 살펴보고, 부족한 부분과 보완 방향을 정리하는 디렉터리입니다.

기존 보고서(v1.0~v5.1)는 "부하 테스트로 병목을 찾고 개선한 과정"을 기록한 것입니다. 이 디렉터리는 그 결과물을 AWS Solutions Architect Associate(SAA) 학습 이후의 시각으로 다시 검토합니다.

## 목적

- 당시의 설계 결정과 그 이유를 다시 정리한다.
- 기존 설계에서 잘 동작한 부분과 부족한 부분을 구분한다.
- 부족한 부분에 대해 AWS 서비스와 설정 기준의 보완 방향을 정리한다.
